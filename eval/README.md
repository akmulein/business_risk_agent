

# Оценка качества системы

Тестовая выборка составлена из реальных отчётов о контрагентах. В основном наборе 100 компаний, каждая используется один раз.

Для оценки сравнительных саммари сформировано 30 групп:
- 10 групп по 2 компании
- 10 групп по 3 компании
- 10 групп по 5 компаний

Для проверки стабильности выбраны 6 групп, для каждой из которых ответ сервиса генерировался трижды. Первый прогон входит в основную выборку, остальные используются только для проверки стабильности и не входят в основную метрику качества.

Во всех прогонах использовалась модель ~deepseek/deepseek-v4-flash-latest.

Проверка разделена на три уровня:

1. Детерминированные тулы. Проверяются корректность расчётов, статусов, ролей, периодов, интерпретация пропущенных значений и отсутствие неподтверждённых выводов.

2. LLM-суммаризатор. Проверяется, не исказила ли модель числа, единицы измерения, принадлежность фактов компании, год, статус или исходный смысл данных.

3. End-to-end. Проверяется корректность работы всего пайплайна: данные из итоговых саммари сопоставляются с исходными отчётами. Если в саммари обнаружена хотя бы одна существенная фактическая ошибка, весь кейс считается не прошедшим проверку.

Результаты оценивались внешним LLM-судьёй. Для более достоверной оценки потребуется настройка и валидация судьи человеком, но это требует дополнительных ресурсов (расходов на LLM-вызовы и человеческую разметку) и выходит за рамки MVP для хакатона :)

# Результаты

**Сравнительные саммари:**

93,3% без существенных фактических ошибок end-to-end

6,7% содержали хотя бы одну существенную ошибку (в 3,3% ошибка пришла из тулов, в 3,3%  - из-за галлюцинации LLM)

**Индивидуальные саммари:**

98%  без существенных фактических ошибок

2%  содержали существенную ошибку (в 1% ошибка пришла из тулов, в 1% - из-за галлюцинации LLM)

**Стабильность:** в 6 из 6 протестированных групп повторные генерации не привели к критическим изменениям фактов или выводов

Ограничения

30 сравнительных сценариев достаточно для MVP и поиска системных дефектов, но недостаточно для полной оценки качества и вывода в прод

Фактическая корректность в рамках MVP проверялась внешним LLM-судьей, далее потребуется настройка судьи и размеченный человеком тестовый набор

*Исходные данные, зафиксированные группы, результаты прогонов доступны в репозитории и могут быть использованы для воспроизведения проверки*
