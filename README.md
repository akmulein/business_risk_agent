## Сервис для автоматизированной проверки и сравнения контрагентов по ИНН

🏆 Проект создан на хакатоне «AI Product Hack» по кейсу Альфа-Банка и стал победителем

## Актуальность

Стандартный отчёт о контрагенте - это нечитаемый огромный массив юридических и финансовых показателей в виде таблиц. На его анализ уходит время. При сравнении нескольких потенциальных контрагентов задача усложняется.

Данный сервис автоматизирует этот процесс: анализирует исходные данные, выделяет значимые риски и сильные стороны и формирует краткий вывод по одной или сразу нескольким компаниям.

## Функционал
![Демо](assets/demo.gif)

- На вход подаются один или несколько ИНН
- Для каждого контрагента сервис получает подготовленный отчёт из базы
- Рассчитываются 6 детерминированных разделов анализа
- Формируется краткое AI-саммари
- При проверке нескольких ИНН дополнительно строится сравнительное саммари, которое выделяет различия между компаниями и помогает сравнить контрагентов между собой
- В чат-боте можно задать уточняющие вопросы по данным отчёта

Если LLM недоступна, возвращается только детерминированная сводка

## Оценка качества

Сервис протестирован на наборе из 100 реальных отчётов контрагентов

**93,3%** сравнительных саммари не содержали существенных фактических ошибок

**3,3%** доля галлюцинаций LLM в сравнительных саммари

**98%** индивидуальных саммари не содержали существенных фактических ошибок

**1%** доля галлюцинаций LLM в индивидуальных саммари

**100%** воспроизводимость ответов при перезапуске

*Полная методология, результаты, ограничения и артефакты прогонов описаны в `eval/README.md`*

# Запуск

Создать локальный .env на основе .env.example:
```bash
cp .env.example .env
```
Указать в .env ключ от openrouter `OPENROUTER_API_KEY` для подключения LLM модели 

После этого запустить:
```bash
docker compose up --build
```
Сервис будет доступен по адресу: [http://localhost:3000](http://localhost:3000)
