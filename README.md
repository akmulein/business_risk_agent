# Описание проекта

Сервис для проверки контрагентов - принимает на вход один или несколько ИНН, анализирует полные отчеты по ним и выдает саммари. MVP для хакатона AI Talent Hub. Отчеты анализируются детерминированно с помощью 6 тулов, далее обрабатываются LLM. В случае ошибки подключения к модели выдается детерминированный результат.

После расчёта тулов индивидуальные саммари и общее сравнение компаний генерируются параллельно. Все суммаризаторы используют результаты тулов; сравнение также получает рассчитанные показатели компаний. Промпты требуют опираться на данные отчётов, но программная проверка фактов в тексте саммари не выполняется.

## Установка

```bash
cp .env.example .env
# указать ключ для подключения к модели OPENROUTER_API_KEY
docker compose up --build
```

## Структура репозитория

```text
src/counterparty_verification/
├── api.py          # HTTP-приложение и сборка зависимостей
├── settings.py     # настройки окружения
├── domain.py       # общие модели данных
├── analysis/       # выполнение анализа, тулы
├── agents/         # LLM-агенты, промпты и провайдер OpenRouter
├── chat/           # сценарии и модели чата по результатам
├── storage/        # адаптеры MongoDB и хранилище сессий
└── mcp/            # MCP-сервер и клиент

frontend/       # интерфейс
tests/          # тесты
docs/rules/     # описание бизнес-правил по разделам
scripts/mongo/  # импорт данных и создание индексов
data/seed/      # исходные данные для сидирования MongoDB
```
