# Методология тестирования AI-агента и тестовый датасет

Для валидации качества работы AI-Оценщика и Q&A-помощника (на базе моделей Qwen/GLM), контроля галлюцинаций на границах данных и проверки следования инструкциям был спроектирован и сгенерирован синтетический датасет **из 20 контрагентов** с ИНН в диапазоне от `7700000001` до `7700000020`.

## 1. Карта соответствия бизнес-параметров ("колонок") и JSON-полей

Поскольку данные хранятся в нормализованном JSON-формате, ниже приведена таблица, которая показывает, какие концептуальные столбцы (бизнес-параметры контрагента) маппятся на реальные ветки JSON-файла `synthetic_counterparties.json`:

| Бизнес-параметр (Концептуальный столбец) | Путь в JSON-структуре контрагента | Значение для анализа и проверки логики агента |
| :--- | :--- | :--- |
| **ИНН организации** (Ключ) | `report.baseInfo.inn` | Основной идентификатор для инициации проверки. |
| **Срок жизни компании** | `report.baseInfo.registrationInfo.yearsFromRegistration` | Возраст бизнеса. Помогает выявить фирмы-однодневки. |
| **Риск-светофор Банка** | `report.zskRiskLevel` | Оценка ЗСК (Знай Своего Клиента): `GREEN`, `YELLOW`, `RED`. |
| **Финансовая устойчивость** | `report.finReports` | Массив за 2023–2025 гг. Оценивает динамику выручки (`proceeds`) и чистой прибыли (`profit`). |
| **Судебная нагрузка** | `report.arbitrationCases` | Массив дел. Фиксирует суммы и количество в роли истца (`plaintiff`) и ответчика (`defendant`). |
| **Исполнительные листы** | `report.executionProceedings` | Массив активных производств. Указывает на непогашенные долги по линии приставов. |
| **Статус юридического лица** | `report.status` | Текущий статус компании (`CURRENT` / `CLOSED`) и причина закрытия/ликвидации (`reasonName`). |
| **Репутационные факторы** | `report.reputationalRisks` | Фиксирует маркеры ФНС (блокировки счетов, массовость адресов/директоров). |

## 3. Как запустить тестирование на датасете

Все ИНН прописаны в файле `synthetic_counterparties.json`. Для проведения ручных или автоматических тестов API-эндпоинта достаточно выполнить POST-запрос:

```bash
# Пример: Запрос проверки по ИНН компании "Богатый, но засуженный"
curl -X POST http://localhost:8000/api/v1/analyses \
  -H 'Content-Type: application/json' \
  -d '{"inn":"7700000009"}'
```

**Ожидаемый результат в логах/ответе бэкенда:**
Модель должна вернуть статус `MEDIUM` и в блоке `summary` или ответах на Q&A указать, что, несмотря на выручку в 3 млрд, судебный иск на 5 млрд в качестве ответчика создает угрозу непрерывности деятельности (Going Concern Risk).
