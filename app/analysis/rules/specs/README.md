# Спецификации правил анализа

В этой папке описано ожидаемое поведение детерминированных анализаторов из `app/analysis/rules/`.

Каждый файл соответствует одному MCP-тулу: например, `analyze_finance.md` описывает проверки финансового раздела, а `analyze_legal.md` — проверки судов и исполнительных производств.

Эти документы нужны не для пользователя интерфейса, а для разработки и ревью: по ним проще понять, почему правило сработало, какие данные оно использует и какие выводы не должно делать без подтверждения в отчёте.
