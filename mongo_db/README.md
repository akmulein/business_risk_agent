# MongoDB

Исходные данные и скрипты для подготовки локальной MongoDB при запуске проекта.

`contractors_audit.snapshot.json` — 100 сырых исходных отчётов о контрагентах.

`seed.sh` — основной сценарий подготовки базы. Он загружает исходные отчёты в MongoDB и по очереди запускает остальные скрипты.

`build_read_model.js` — собирает из сырых отчётов подготовленные карточки `counterparty_cards`, которые читает backend.

`create_indexes.js` — создаёт индексы для быстрого поиска по ИНН и служебным полям.

Эти файлы не нужно запускать вручную: достаточно выполнить `docker compose up --build` из корня проекта.
